# Course Management System

## Project Description

The Course Management System is a web-based application used to manage online courses and student enrollments.

This project allows users to:

- Add new courses
- View available courses
- Enroll in courses
- View enrolled students
- Delete courses
- Search courses
- Filter courses by category

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

### 1. Course Management

The admin can add new courses by entering:

- Course name
- Instructor name
- Course category
- Course duration
- Course description

### 2. Course Display

All available courses are displayed as colorful course cards.

Each course card contains:

- Course title
- Instructor name
- Category
- Duration
- Description
- Enroll button
- Delete button

### 3. Student Enrollment

Students can enroll in available courses by clicking the Enroll button.

The enrollment details are displayed in the enrollment section.

### 4. Search Function

Users can search for courses by entering the course name or instructor name.

### 5. Category Filter

Courses can be filtered based on categories such as:

- Programming
- Database
- Web Development
- Artificial Intelligence
- Data Science

## How to Run the Project

1. Create a folder named `Course Management System`.
2. Create the following files inside the folder:

   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`

3. Paste the respective codes into each file.
4. Open the `index.html` file in a web browser.
5. The Course Management System will be displayed.
